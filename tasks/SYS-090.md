# SYS-090 — Harden the task tools

User request 2026-11-08, after [SYS-088](SYS-088.md). In progress on branch
`agent/tasks-tools`:

1. `next`/`new` reserve IDs under a lock in the shared git directory, and also
   see uncommitted task files in other worktrees.
2. `migrate --base <commit>` converts only the tasks a branch added or changed.
3. The check fails when the monthly archive is due (month taken from the
   changelog header).
4. The check verifies `#anchor` parts of links into and out of `tasks/`.
5. Tests for the script, run in `nix flake check`.
6. Open tasks with only `reviewed:` get `review:` = reviewed + 14 days.
7. Warnings for closed tasks that are long or lack a changelog link.

Done when: all seven are merged, the tests and `nix flake check` pass, and two
`new` runs started at the same moment get different IDs.
