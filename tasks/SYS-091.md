# SYS-091 — One file per changelog entry

`SYSTEM_CHANGELOG.md` has the problem `SYSTEM_TODO.md` had before
[SYS-088](SYS-088.md): several agents add entries at the top of one file,
which is held together by `merge=union` (duplicated lines after merges). Split
it into one file per entry (for example `changelog/2026-11/2026-11-08-<slug>.md`)
and generate the monthly view.

Open questions: whether to generate the monthly file or only show it with
a script; how to keep the existing anchors that tasks and `SYSTEM_CONTEXT.md`
link to; how `[PENDING]` checkpoint entries are written and read back.

Done when: entries are separate files, links from tasks and context resolve
(checked in `nix flake check`), AGENTS.md describes the new workflow, and two
branches adding entries merge without conflicts or duplicates.
