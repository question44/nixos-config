# SYS-093 — macOS JetBrains shortcuts in Zed

Zed uses the macOS JetBrains keymap with Super as Cmd (generation 322). On
2026-11-08 the user confirmed the shortcuts work with the real keyboard.
Umbriel kept Super+0. Evidence and the list of removed Umbriel binds are in the
[changelog entry](../SYSTEM_CHANGELOG.md) "Zed: macOS JetBrains keymap with Cmd
on Super (SYS-093)".
