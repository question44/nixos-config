# SYS-092 — Task board card in the hub

Optional, after [SYS-090](SYS-090.md). Add an admin-only, read-only card to
the dashboard hub: open and active tasks, overdue reviews, and epic progress
(for example SYS-087: 0 of 6 done). Data comes from `scripts/erebor-tasks`
(add a `--json` output) or from a file generated at build time from `tasks/`.

Done when: the admin sees the card with correct counts and links to the task
files; other accounts do not see it.
