# SYS-097 — Trim desktop packages: speech-dispatcher, Tesseract languages, Chrome, Konsole, XFCE→LXQt for xrdp, Tauon, Flatpak and Discover, Spotify desktop app behind a toggle

Asked by the user on 2026-11-11 after a disk cleanup (root was 97% full;
evidence below is from that session's store analysis of generation 370).

1. **Disable text-to-speech.** `services.speechd.enable` is true only through
   nixpkgs' `graphical-desktop.nix` default. The system service uses the full
   `speechd` package, whose eSpeak NG build pulls every MBROLA voice
   (`mbrola-voices`, 0.68 GB). Browsers and Qt link a separate minimal
   libspeechd without mbrola. Set `services.speechd.enable = false;` in the
   workstation profile. Accepted effect: no system voices for browser
   read-aloud / Web Speech API.
2. **Tesseract with English and Polish only.** `tesseract` in
   `modules/workstation/packages.nix` pulls tessdata for every language
   (the `-all` path, 1.06 GB). Replace with
   `(tesseract.override { enableLanguages = [ "eng" "pol" ]; })`
   (evaluates; output not yet built).
3. **Remove Google Chrome** (0.47 GB): the package (with its
   `--password-store=gnome-libsecret` override) and its unfree allowlist entry
   in `modules/workstation/packages.nix`. The default browser is Helium.
   Its profile data is deleted in the cleanup step below.
   The `~/.local/share/applications/chrome-*-Default.desktop` launchers
   ("erebor services", "T3 Code", "ChatGPT") and their `chrome-*` icons are
   **Helium** web apps (Chromium's naming), not Chrome's: keep them.
4. **Remove Konsole** (`kdePackages.konsole` in
   `modules/workstation/packages.nix`). Also drop `"konsole"` from Noctalia's
   theme-template list in `home/noctalia/config.toml`. The `konsole` /
   `org.kde.konsole` matches in `home/xremap/config.yml` are harmless
   app filters; remove them only if tidying.
5. **Replace XFCE with LXQt in the xrdp session; keep xrdp.** The XFCE apps
   (Thunar, xfce4-terminal, panel, settings) exist only for
   `modules/remote-desktop.nix` (xrdp over Tailscale). The user chose
   (2026-11-11) to keep xrdp and run LXQt instead: it is Qt-based, so it
   shares the Qt/KDE libraries already installed for Dolphin, Okular and
   Gwenview, which also look native in it. Replace `desktopPackages` with the
   LXQt session pieces (nixpkgs `lxqt.*`, 2.4.0 at the time) plus a terminal,
   start `startlxqt` from the session script with the same environment
   isolation (X11, separate D-Bus), and drop `programs.xfconf` and
   `/share/xfce4`. XFCE plus xrdp added about 240 MB unique to the closure,
   including `libmateweather`/`mate-panel` (119 MB + 15 MB; find out what
   pulls them). Verify by logging in over RDP through Tailscale: the panel,
   a terminal and Dolphin open.
6. **Remove Tauon:** the `tauon` override (pypresence pin) and the package in
   `modules/workstation/packages.nix`. Keep fooyin.
7. **Remove Flatpak, Linksy and Discover.** Linksy
   (`mg.diary.linksy.Linksy`) is the only Flatpak app; with its runtimes
   `/var/lib/flatpak` is 2.6 GB. Before disabling, run
   `flatpak uninstall --all --delete-data` (Linksy's `~/.var/app` data is
   3.1 MB) and `sudo flatpak uninstall --unused`. Then remove `services.flatpak.enable`, the
   `flatpak-flathub` service, `kdePackages.discover` and the three
   `application/vnd.flatpak*` MIME associations in `modules/home/desktop.nix`.
8. **Put the official Spotify desktop app behind a toggle; keep Spotifast.**
   Add `my.spotify.desktopApp.enable` (`mkEnableOption`, off by default) in
   `modules/my.nix`, and leave it off on erebor. In `modules/spotify.nix`,
   gate the Spicetify-patched `spotify` wrapper, `spicetify-cli` and
   `spotifyLauncher` on it, and the Home Manager half (Comfy theme files,
   `spotifyNoctaliaTheme` activation) on `osConfig.my.spotify.desktopApp.enable`.
   Keep the `spotifast` override unconditional (it downloads its own Soloist
   player into `~/.local/state/spotifast`, independent of `pkgs.spotify`).
   Move `spotifyLauncher` from `modules/workstation/packages.nix` into the
   gated part. `nixosConfigurations.template` must evaluate with it off.
   With it off, follow-ups: Noctalia's dock pin `com.spotify.Client`
   (`home/noctalia/config.toml`, `pinned`) and its app list entries, the
   Umbriel window rule `^spotify$` and the `*spotify*` case in
   `home/umbriel/caps-q-window` (harmless if kept); check that the
   `spotify-lyrics` and `spotify-media-niri` Noctalia plugins still work with
   Spotifast (MPRIS). Ask whether `spotify-player` (terminal client, also used
   by the Vicinae Raycast keybinding) stays. Its user data is deleted in the
   cleanup step below.

9. **Delete the removed apps' data (user decision, 2026-11-11), after
   activation and only for apps that are gone.** Sizes measured 2026-11-11:
   - Chrome: `~/.config/google-chrome` (900 MB) and `~/.cache/google-chrome`
     (58 MB) only. Do not touch the `chrome-*` launchers or icons; they
     belong to Helium.
   - Spotify desktop app: `~/.local/share/spotify-noctalia` (1.2 GB),
     `~/.cache/spotify` (542 MB), `~/.config/spotify`, `~/.config/spicetify`.
     Keep `~/.local/state/spotifast`.
   - Flatpak: `/var/lib/flatpak` (2.6 GB), `~/.local/share/flatpak`,
     `~/.cache/flatpak`, `~/.var/app`.
   - Discover: `~/.cache/discover`, `~/.config/discoverrc`.
   - Tauon: `~/.local/share/TauonMusicBox`, `~/.cache/TauonMusicBox`.
   - Konsole: `~/.config/konsolerc`, `~/.config/konsolesshconfig`,
     `~/.local/share/konsole`.
   - XFCE: `~/.config/xfce4`, `~/.config/Thunar`, `~/.cache/xfce4`, once the
     LXQt session works over RDP.
   List each path before deleting it; delete files only, never with a glob
   that could reach other apps' data.

Check with `scripts/erebor-diff` that only these packages leave the closure
(Chrome's minimal libspeechd may stay through other apps; Konsole's KDE
libraries may stay through Dolphin and KDE Connect).

Done when: the change is activated through `scripts/erebor-rebuild switch`;
`speech-dispatcher` and `mbrola-voices`, `google-chrome`, `konsole`, the XFCE
packages, `tauon`, `flatpak`, `discover` and the official `spotify` are no
longer in `/run/current-system`'s closure; an RDP login gets an LXQt desktop;
`spotifast` still plays music; a build with `my.spotify.desktopApp.enable =
true` brings the themed Spotify back; the `flatpak` command and
`/var/lib/flatpak` are gone; `tesseract --list-langs` shows only `eng`, `osd`
(if kept) and `pol`; the paths in step 9 no longer exist; and the changelog
records the closure-size difference and the space freed (about 8 GB expected).
