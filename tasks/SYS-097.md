# SYS-097 — Trim desktop packages: speech-dispatcher, Tesseract languages, Chrome, Konsole, XFCE remote desktop, Tauon, Flatpak and Discover, Spotify desktop app

Asked by the user on 2026-11-11 after a disk cleanup (root was 97% full;
evidence below is from that session's store analysis of generation 370).

1. **Disable text-to-speech.** `services.speechd.enable` is true only through
   nixpkgs' `graphical-desktop.nix` default. The system service uses the full
   `speechd` package, whose eSpeak NG build pulls every MBROLA voice
   (`mbrola-voices`, 0.68 GB). Browsers and Qt link a separate minimal
   libspeechd without mbrola. Set `services.speechd.enable = false;` in the
   workstation profile. Accepted effect: no system voices for browser
   read-aloud / Web Speech API.
2. **Tesseract with English and Polish only.** `tesseract` in
   `modules/workstation/packages.nix` pulls tessdata for every language
   (the `-all` path, 1.06 GB). Replace with
   `(tesseract.override { enableLanguages = [ "eng" "pol" ]; })`
   (evaluates; output not yet built).
3. **Remove Google Chrome** (0.47 GB): the package (with its
   `--password-store=gnome-libsecret` override) and its unfree allowlist entry
   in `modules/workstation/packages.nix`. The default browser is Helium.
   Leave the profile in `~/.config/google-chrome` (900 MB) and
   `~/.cache/google-chrome` alone unless the user agrees to delete them.
   Three Chrome web apps in `~/.local/share/applications/chrome-*-Default.desktop`
   ("erebor services", "T3 Code", "ChatGPT") break without Chrome: reinstall
   them as Helium web apps first, then remove the stale launchers.
4. **Remove Konsole** (`kdePackages.konsole` in
   `modules/workstation/packages.nix`). Also drop `"konsole"` from Noctalia's
   theme-template list in `home/noctalia/config.toml`. The `konsole` /
   `org.kde.konsole` matches in `home/xremap/config.yml` are harmless
   app filters; remove them only if tidying.
5. **Remove the XFCE remote-desktop session.** The XFCE apps (Thunar,
   xfce4-terminal, panel, settings) exist only for `modules/remote-desktop.nix`
   (xrdp over Tailscale), imported by `modules/workstation/default.nix`.
   Removing them means dropping that aspect, so xrdp goes too: no xrdp-sesman
   logins in the journal for the last 60 days (checked 2026-11-11). Also drop
   `programs.xfconf` with it. Confirm with the user before removing xrdp
   itself, if a different remote session is wanted instead.
6. **Remove Tauon:** the `tauon` override (pypresence pin) and the package in
   `modules/workstation/packages.nix`. Keep fooyin.
7. **Remove Flatpak, Linksy and Discover.** Linksy
   (`mg.diary.linksy.Linksy`) is the only Flatpak app; with its runtimes
   `/var/lib/flatpak` is 2.6 GB. Before disabling, run
   `flatpak uninstall --all --delete-data` (Linksy's `~/.var/app` data is
   3.1 MB). Then remove `services.flatpak.enable`, the
   `flatpak-flathub` service, `kdePackages.discover` and the three
   `application/vnd.flatpak*` MIME associations in `modules/home/desktop.nix`.
8. **Remove the official Spotify desktop app; keep Spotifast.** In
   `modules/spotify.nix` drop the Spicetify-patched `spotify` wrapper,
   `spicetify-cli`, the prepare script and the Home Manager half
   (Comfy theme files, `spotifyNoctaliaTheme` activation); keep the
   `spotifast` override (it downloads its own Soloist player into
   `~/.local/state/spotifast`, independent of `pkgs.spotify`). Drop
   `spotifyLauncher` and its `spotify` exec from
   `modules/workstation/packages.nix`, and `spotify` from the unfree
   allowlist if listed. Follow-ups: Noctalia's dock pin `com.spotify.Client`
   (`home/noctalia/config.toml`, `pinned`) and its app list entries, the
   Umbriel window rule `^spotify$` and the `*spotify*` case in
   `home/umbriel/caps-q-window`; check that the `spotify-lyrics` and
   `spotify-media-niri` Noctalia plugins still work with Spotifast (MPRIS).
   Ask whether `spotify-player` (terminal client, also used by the Vicinae
   Raycast keybinding) stays. Leftover user data to offer for deletion:
   `~/.local/share/spotify-noctalia`, `~/.config/spicetify`,
   `~/.config/spotify`, `~/.cache/spotify`.

Check with `scripts/erebor-diff` that only these packages leave the closure
(Chrome's minimal libspeechd may stay through other apps; Konsole's KDE
libraries may stay through Dolphin and KDE Connect).

Done when: the change is activated through `scripts/erebor-rebuild switch`;
`speech-dispatcher` and `mbrola-voices`, `google-chrome` and `konsole`, the XFCE
packages and xrdp, `tauon`, `flatpak` and `discover`, and the official
`spotify` are no longer in `/run/current-system`'s closure; `spotifast`
still plays music; the `flatpak` command and `/var/lib/flatpak` are gone;
`tesseract --list-langs` shows only `eng`, `osd` (if kept) and `pol`; and the changelog records the closure-size
difference.
